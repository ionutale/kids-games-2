# Khan Academy Kids — Games & Activities (officially documented)

One Markdown file per game, song, video, book mode, activity type, or collection that Khan
Academy **officially names or concretely describes** in its own published materials.

> **This is not the full catalog.** Khan Academy Kids advertises 5,000+ games, books, and videos,
> but Khan Academy does not publish an itemized public list — the in-app Library is the
> authoritative "full scope" of the app. The files here cover only the entries verifiable in
> official sources. The rest (thousands of unnamed lessons, 400+ book titles) are not
> individually documented in public. See the sibling research notes at
> [`../khan-academy-kids-games.md`](../khan-academy-kids-games.md) for categories, counts, and
> caveats.

Every file links the official source for its claims. Nothing here is invented; where official
sources only give a title, the file says so. Sources retrieved 2026-09-20. Content, names, and
availability can vary by app version, profile level, platform, and season.

## What is *not* covered here

- **Unnamed Library content** — the thousands of lessons and activities inside the Letters,
  Reading, Math, and Logic+ tabs, and most of the 400+ book titles, are not individually named in
  official sources.
- **Printable activity packets** — Khan Academy also publishes paper activity packets (math,
  literacy, writing & coloring, social-emotional & science, fun & play, seasonal), but these are
  printouts, not in-app games.
