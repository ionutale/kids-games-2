# Storytelling and voice recording

- **Type:** Activity (creative tool)
- **Library section:** Create
- **Subject:** Creative expression — storytelling, self-expression
- **Levels:** Create content is not level-filtered in official descriptions
- **Sources:** [Help Center — How to use creative tools inside the Khan Kids app](https://khankids.zendesk.com/hc/en-us/articles/21188738836763-How-to-use-creative-tools-inside-the-Khan-Kids-app),
  [Help Center — Find books and lessons in the Library](https://khankids.zendesk.com/hc/en-us/articles/4403657703821-Find-books-and-lessons-in-the-Khan-Kids-Library)

## Description

Children can build stories in the Create tab: draw and color scenes, add stickers, record their
voice, and play the recording back. Creations are saved to a Gallery and can be exported to the
camera roll.

## Notes

- "Storytelling" is listed among the Create tab's content in the official Library article.
