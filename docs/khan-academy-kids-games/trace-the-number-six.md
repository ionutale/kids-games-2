# Trace the number six

- **Type:** Math activity
- **Library section:** Math (numeral formation)
- **Subject:** Math — number recognition and numeral writing
- **Levels:** Kindergarten (the blog presents it among Kindergarten math games)
- **Source:** [Khan Academy Blog — Free Kindergarten Math Games](https://blog.khanacademy.org/free-kindergarten-math-games)

## Description

Children trace the numeral six. The blog notes that tracing numerals helps kids memorize their
shape.
