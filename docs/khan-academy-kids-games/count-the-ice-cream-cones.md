# Count and tap the ice cream cones

- **Type:** Math activity
- **Library section:** Math
- **Subject:** Math — counting and number sense (1:1 correspondence)
- **Levels:** Kindergarten (the blog presents it among Kindergarten math games)
- **Source:** [Khan Academy Blog — Free Kindergarten Math Games](https://blog.khanacademy.org/free-kindergarten-math-games)

## Description

Children practice 1:1 correspondence by tapping the ice cream scoops one by one; each time they
tap a scoop, a number appears above it.
