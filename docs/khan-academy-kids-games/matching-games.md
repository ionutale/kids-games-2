# Matching games (Logic+)

- **Type:** Activity type — not individually named in official sources
- **Library section:** Logic+
- **Subject:** Executive function & logic — focus, memory, flexible thinking
- **Levels:** The Logic+ tab can be filtered Preschool–2nd Grade
- **Sources:** [Help Center — Find books and lessons in the Library](https://khankids.zendesk.com/hc/en-us/articles/4403657703821-Find-books-and-lessons-in-the-Khan-Kids-Library),
  [Help Center — Parent guide](https://khankids.zendesk.com/hc/en-us/articles/360006764812-Parent-and-Home-Account-Users-Getting-Started-and-creating-an-account-with-Khan-Academy-Kids)

## Description

Matching games are listed among the Logic+ tab's activities, alongside memory games and activities
that help kids follow directions. The app pairs Logic+ with social-emotional lessons about
feelings and emotions, and the tab also contains songs.

## Notes

- Official sources describe this activity type but do not name individual matching games; there is
  no per-game file because no titles are published.
