# Drawing and coloring

- **Type:** Activity (creative tool)
- **Library section:** Create
- **Subject:** Creative expression
- **Levels:** Create content is not level-filtered in official descriptions
- **Sources:** [Help Center — Find books and lessons in the Library](https://khankids.zendesk.com/hc/en-us/articles/4403657703821-Find-books-and-lessons-in-the-Khan-Kids-Library),
  [Help Center — How to use creative tools inside the Khan Kids app](https://khankids.zendesk.com/hc/en-us/articles/21188738836763-How-to-use-creative-tools-inside-the-Khan-Kids-app)

## Description

The Create tab includes coloring pages (animals, vehicles, app characters, and seasonal pages),
backgrounds, stickers, and colored pencils/crayons including a rainbow crayon, with an undo
option. Creations are saved to a Gallery and can be exported to the device's camera roll.

- Create also covers storytelling and voice recording; see
